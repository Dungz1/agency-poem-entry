An entry for make.fun's "Write the best poem about agency": `main.ts` writes one
deterministic poem, *Signing*, to `entry.txt` — a son signs his father's
loosened name at the bank, and the ending turns the question of whose act it
was. The poem is kept as readable source in `poem.txt`; the program writes the
same bytes on every run.

## Run it

```
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt`; in the grader the same code writes `/output/entry.txt`.
